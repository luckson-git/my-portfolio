PREDICTIVE ANALYTICSPROJECT 01

Car Resale
Price Prediction

Estimating used-car value from vehicle specifications and ownership history.

  • Python
  • pandas
  • scikit-learn
  • Linear regression
Explore project on GitHub ↗

The question

Can vehicle attributes help estimate resale prices and support market pricing decisions?

The approach

Validate the data, remove identifiers, split training and test records, encode categories, and evaluate a linear-regression baseline.

The deliverables

A runnable training script, an actual-versus-predicted diagnostic chart, and a coefficient table for inspecting feature effects.

CAPSTONE R²0.9426
MEAN ABSOLUTE ERROR0.7795 lakh
ROOT MEAN SQUARED ERROR1.1621 lakh

Evaluation context. These are reported results from the original capstone notebook’s 20% test split. The current workflow uses one-hot encoding instead of the notebook’s label encoding. The original dataset is not included; these metrics have not been independently rerun and should be revalidated with an authorized dataset.

Employee Attrition
Dashboard

Exploring how employee attrition varies across departments, job roles, overtime groups, and tenure.

  • Power BI
  • Power Query
  • DAX
  • Data visualization
Explore dashboard project ↗Download Power BI project ↓

The question

Which employee groups have the highest share of records marked as having left?

The approach

Check 1,470 employee records, define group-level attrition measures in DAX, and compare departments, overtime, roles, and tenure with interactive filters.

The deliverables

A two-page Power BI project, an embedded data snapshot, KPI cards, comparison charts, and documented measures and opening instructions.

EMPLOYEE RECORDS1,470
MARKED AS LEFT237
ATTRITION SHARE16.1%

Analysis context. Attrition share is Yes records divided by all records in each group. The dataset has no reporting period, so this is not an annual turnover rate. Comparisons show associations, not causes. Data totals and report definitions were checked; native Power BI rendering remains untested.
