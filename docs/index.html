PREDICTIVE ANALYTICSPROJECT 01

Car Resale
Price Prediction

Estimating used-car value from vehicle specifications and ownership history.

  • Python
  • pandas
  • scikit-learn
  • Linear regression
Explore project on GitHub ↗

The question

Can vehicle attributes help estimate resale prices and support market pricing decisions?

The approach

Validate the data, remove identifiers, split training and test records, encode categories, and evaluate a linear-regression baseline.

The deliverables

A runnable training script, an actual-versus-predicted diagnostic chart, and a coefficient table for inspecting feature effects.

CAPSTONE R²0.9426
MEAN ABSOLUTE ERROR0.7795 lakh
ROOT MEAN SQUARED ERROR1.1621 lakh

Evaluation context. These are reported results from the original capstone notebook’s 20% test split. The current workflow uses one-hot encoding instead of the notebook’s label encoding. The original dataset is not included; these metrics have not been independently rerun and should be revalidated with an authorized dataset.
